# CareerPath AI — Next.js Application Root

This folder contains the core full-stack Next.js application for **CareerPath AI**.

For complete architecture, feature lists, and local setup instructions, please refer to the main repository [README.md](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Push database schema
npm run db:push

# 3. Start local development server
npm run dev
```

For environment variables, copy `.env.example` to `.env.local` and add your Clerk, Gemini AI, and Neon PostgreSQL keys.
