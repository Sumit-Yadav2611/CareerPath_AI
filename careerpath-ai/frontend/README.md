# CareerPath AI — Frontend UI Components & Design System

This folder encapsulates all client-side user interface components, interactive features, and design tokens for **CareerPath AI**.

## Structure

```text
frontend/
└── components/
    ├── hero/
    │   └── CareerPathAiBotHero.tsx   # 3D/cyberpunk floating AI Bot with orbiting message cards
    ├── dashboard/
    │   ├── Sidebar.tsx               # Dashboard navigation sidebar with icons & active states
    │   ├── DashboardHeader.tsx       # User greeting, search & notifications
    │   ├── JobCard.tsx               # Smart job card with matching score & 1-click apply
    │   ├── JobsSection.tsx           # Categorized job listings & filter controls
    │   ├── ProfileCompleteness.tsx   # Visual progress indicator
    │   ├── RecommendedJobs.tsx       # Personalized AI recommended roles
    │   └── ResumeUpload.tsx          # Drag-and-drop resume uploader with instant validation
    ├── ui/
    │   └── button.tsx                # Accessible design system button primitive
    ├── Navbar.tsx                    # Top navigation bar with logo, links & auth actions
    ├── Footer.tsx                    # Footer with creator attribution & social profile links
    ├── Features.tsx                  # Interactive platform feature cards
    ├── HowItWorks.tsx                # Step-by-step career acceleration walkthrough
    └── CTA.tsx                       # High-impact call-to-action banner
```

## Technologies
- **React 19 & Next.js 16**
- **Tailwind CSS 4**
- **Lucide React Icons**
